# Retro Notes 95

Windows 95風の小さな窓に、そのまま文字を書けるデスクトップ付箋です。
青いタイトルバー、灰色の立体的な枠、ドット文字を組み合わせました。

## はじめ方

1. ZIPを右クリックして「すべて展開」します。
2. 展開した `RetroNotes95` フォルダーを、使い続けたい場所に置きます。
3. フォルダーの中の **RetroNotes95.exe** をダブルクリックします。
4. 白い部分にメモを入力します。入力が止まって約0.6秒後に自動保存します。

`assets` フォルダーなども一緒に置いてください。EXEだけを移動する代わりに、
EXEのショートカットをデスクトップに作ると便利です。

対象はWindows 11です。.NET Framework 4.8以降を使います。
通常のWindows 11には含まれているため、PythonやNode.jsのインストールは不要です。
管理者権限も不要です。

## 基本操作

| やりたいこと | 操作 |
| --- | --- |
| 新しい付箋を作る | File → 新しい付箋 / Ctrl+N |
| 移動する | タイトルバーをドラッグ |
| 大きさを変える | 右下の斜線部分をドラッグ |
| 付箋の名前を変える | タイトルバーをダブルクリック / F2 |
| 大きく表示する・戻す | 右上の最大化ボタン |
| 他のアプリより手前に置く | 右下の PIN OFF を押して PIN ON にする |
| 付箋を隠す | × / 最小化ボタン / Ctrl+W |
| 隠した付箋を戻す | 時計の近くの付箋アイコンをダブルクリック |
| 1枚だけ選んで戻す | 時計の近くの付箋アイコンを右クリックし、付箋名を選ぶ |
| 文字サイズ・色・書体を変える | View メニュー |
| 削除する | File → この付箋を削除 |
| アプリを終了する | File → アプリを終了、または付箋アイコンの右クリック → 終了 |

**×を押しても削除されません。** 隠した状態のまま内容を保存します。
もう一度EXEを開いても、すでに起動している場合は付箋を呼び戻します。
アイコンが見えないときは、時計の近くの「隠れているインジケーター」を開いてください。

PIN OFFでは、普通のアプリと同じように、別のウィンドウの後ろに回ります。
**Win+Dを押すと付箋も隠れる場合があります。** その場合は付箋アイコンから再表示できます。
Windowsの壁紙・デスクトップアイコン・タスクバーの設定は変更しません。

## 自動起動

View → **Windowsと一緒に起動** をオンにすると、次のWindowsサインインから起動します。
初期状態はオフです。フォルダーの場所を変えたときは、この設定を一度オフにしてからオンに戻してください。

## 保存とバックアップ

本文、付箋の名前、位置、大きさ、色、文字サイズ、PINの状態、隠した状態を保存します。
メモの内容をインターネットへ送信する機能はありません。

保存先:

`%LOCALAPPDATA%\RetroNotes95\notes.json`

保存前の状態は `notes.json.bak` に残します。保存ファイルが読み込めない場合は、
読み込めなかった元のファイルを残し、バックアップからの復元を試みます。

- **File → テキストを書き出す**: その付箋をUTF-8の `.txt` として保存。
- **File → すべての付箋をバックアップ**: 全付箋を `.json` に書き出し。
- **File → バックアップを取り込む**: 現在の付箋を残して、バックアップの付箋を追加。
- **File → 保存フォルダーを開く**: 保存場所を開く。

保存に失敗した場合はステータス欄に表示します。その場合はアプリを閉じる前に、
テキスト書き出しなどで別の場所に内容を保存してください。

## キーボード

付箋にフォーカスがあるときに使えます。

- Ctrl+N: 新規
- Ctrl+S: 即時保存
- Ctrl+W: 隠す
- Ctrl+Shift+P: PIN切り替え
- Ctrl+Shift+E: テキスト書き出し
- Ctrl+Shift+S: 全付箋のバックアップ
- F2: 名前変更
- F1: 使い方
- Ctrl+A / C / V / X / Z: 全選択 / コピー / 貼り付け / 切り取り / 元に戻す

## ファイルと動作確認

`src` にソースコード、`Build-Windows.cmd` にWindowsでの再ビルド手順を同梱しています。
普段使うときは再ビルド不要です。

Windows向け実行ファイルのビルド、および互換環境での保存・復元とGUIの確認を行っています。
**Windows 11実機、日本語IMEの変換、Windowsのサインイン時の自動起動は実機未検証です。**
この初版はコード署名を付けていません。

削除するときは自動起動をオフにして終了し、アプリのフォルダーを削除してください。
メモの保存フォルダーは残るため、再導入したときに読み込めます。
